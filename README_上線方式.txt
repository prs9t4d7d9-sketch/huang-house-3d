黃宅｜互動 3D 設計匯報｜正式網站部署包

這是一個「靜態網站」部署包，不需要 Node.js、資料庫或後端。

網站入口：
  index.html

最簡單的上線方式：
1. 將整個資料夾內容上傳到任何 Static Hosting。
2. 設定網站根目錄（Publish/Root Directory）為本資料夾。
3. 入口檔案使用 index.html。
4. 上線後用 iPhone Safari 開啟網址即可。

適用：
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- 任何可直接託管 HTML/CSS/JS 的網站空間

iPhone：
Safari 開啟網站 → 分享 → 加入主畫面。
manifest.webmanifest 已一併提供，可作為 PWA 基礎設定。

注意：
目前 3D 為依 AR-01 平面配置重建的「設計匯報級示意 3D」，不是 BIM/施工級精確模型。
